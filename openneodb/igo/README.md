# iGoExt

Каталог содержит `IGoReader`, который только читает текстовый экспорт
SpeedCamOnline iGoExt и возвращает нормализованные `CameraRecord`.

## Формат

Файл — UTF-8 CSV с заголовком:

```text
IDX,X,Y,TYPE,SPEED,DIRTYPE,DIRECTION
```

| Поле | Значение |
| --- | --- |
| `IDX` | идентификатор исходной записи; при конвертации не используется |
| `X` | долгота в градусах |
| `Y` | широта в градусах |
| `TYPE` | тип камеры |
| `SPEED` | ограничение скорости, км/ч |
| `DIRTYPE` | направленность: `0`, `1` или `2`; переносится без изменения |
| `DIRECTION` | направление движения, `0`…`359` градусов |

Координаты сохраняются как `floor(value × 10000)`; поддерживаются только
северная широта `0`…`90` и восточная долгота `0`…`180`. Пустые `SPEED`,
`DIRTYPE` и `DIRECTION` заменяются соответственно на `0`, `1` и `0` с
предупреждением. Строка с пустыми координатами, некорректным числом,
значением вне диапазона или лишними колонками пропускается с
предупреждением.

## Преобразование типов

| iGo `TYPE` | Neoline | Назначение |
| --- | --- | --- |
| `192` | `0x06` | стационарный радар |
| `68` | `0x01` | безрадарный комплекс; дополнительно `flags = 0x02` |
| `199` | `0x4A` | контроль средней скорости |
| `206` | `0x07` | пост ДПС |
| `227` | `0x06` | весовой контроль как стационарный радар |
| любой другой непустой | `0x06` | базовый стационарный радар с предупреждением |

Пустой `TYPE` приводит к пропуску строки с предупреждением. Вторая точка,
флаги (кроме типа `68`), допуск по курсу и дистанция предупреждения
заполняются нулями.
