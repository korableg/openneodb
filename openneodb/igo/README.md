# iGo и iGoExt

Каталог содержит два reader для текстовых баз камер; оба только читают файл
и возвращают нормализованные `CameraRecord`:

- `IGoReader` — формат iGo, пять обобщённых типов;
- `IGoExtReader` — формат iGoExt, подробные типы.

Форматы отличаются только кодами `TYPE`, остальная структура общая. iGoExt
точнее: только в нём пост ДПС отделён от стационарной камеры.

## Формат

Файл — UTF-8 CSV с заголовком:

```text
IDX,X,Y,TYPE,SPEED,DIRTYPE,DIRECTION
```

| Поле | Значение |
| --- | --- |
| `IDX` | идентификатор исходной записи; при конвертации не используется |
| `X` | долгота в градусах |
| `Y` | широта в градусах |
| `TYPE` | тип камеры |
| `SPEED` | ограничение скорости, км/ч |
| `DIRTYPE` | направленность: `0`, `1` или `2`; переносится без изменения |
| `DIRECTION` | направление движения, `0`…`359` градусов |

Координаты сохраняются как `floor(value × 10000)`; поддерживаются только
северная широта `0`…`90` и восточная долгота `0`…`180`. Пустые `SPEED`,
`DIRTYPE` и `DIRECTION` заменяются соответственно на `0`, `1` и `0` с
предупреждением. Строка с пустыми координатами, некорректным числом,
значением вне диапазона или лишними колонками пропускается с
предупреждением.

## Преобразование типов

### iGo

| `TYPE` | Neoline | Назначение |
| --- | --- | --- |
| `1` | `0x06` | стационарная камера, включая посты ДПС |
| `3` | `0x01` | безрадарный комплекс; дополнительно `flags = 0x02` |
| `4` | `0x06` | весовой контроль как стационарный радар |
| `5` | `0x4A` | контроль средней скорости |
| любой другой непустой | `0x06` | базовый стационарный радар с предупреждением |

### iGoExt

| `TYPE` | Neoline | Назначение |
| --- | --- | --- |
| `192` | `0x06` | стационарный радар |
| `68`, `197` | `0x01` | безрадарный комплекс; дополнительно `flags = 0x02` |
| `199`, `193` | `0x4A` | контроль средней скорости |
| `206` | `0x07` | пост ДПС |
| `227` | `0x06` | весовой контроль как стационарный радар |
| любой другой непустой | `0x06` | базовый стационарный радар с предупреждением |

Соответствие кодов установлено сопоставлением баз обоих форматов по `IDX`: iGo `1` —
это iGoExt `192` и `206`, `3` — `68` и `197`, `4` — `227`, `5` — `199` и
`193`, `2` — `194`.

Пустой `TYPE` приводит к пропуску строки с предупреждением. Вторая точка,
флаги (кроме безрадарных комплексов), допуск по курсу и дистанция
предупреждения заполняются нулями.

Если неизвестных типов больше половины записей, файл считается базой
другого формата (например, iGo, поданный в `IGoExtReader`), и чтение
завершается `IGoFormatError` без результата.
