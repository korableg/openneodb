# CityGuide Speedcam v2

Каталог содержит `CityGuideReader`, который только читает CityGuide BKM и
возвращает нормализованные `CameraRecord`.

## Формат

Файл — текст в кодировке CP1251 с CRLF. Заголовок имеет фиксированный вид:

```text
2|Radars|1251
```

Каждая следующая строка:

```text
TYPE|ID|LAT|LON|TAG|VALUE|TAG|VALUE|...|
```

| Поле или тег | Значение |
| --- | --- |
| `TYPE` | тип объекта CityGuide |
| `ID` | идентификатор; при конвертации не используется |
| `LAT`, `LON` | координаты в градусах |
| `1709` | ограничение скорости, км/ч |
| `1713` | направленность CityGuide |
| `1705` | азимут камеры, `0`…`359` |
| `1706` | дистанция предупреждения в метрах |

Координаты сохраняются как `floor(value × 10000)`; поддерживаются только
северная широта `0`…`90` и восточная долгота `0`…`180`. Азимут камеры
переводится в направление движения добавлением 180° по модулю 360. Дистанция
делится на 10 с округлением вниз и приводится к пределам RevM60: больше
2000 м ограничивается 2000 м (прошивка читает `>200` декаметров как 500 м),
от 1 до 9 м поднимается до 100 м (`0` означает 500 м), оба случая — с
предупреждением.

Отсутствующие теги получают безопасные значения с предупреждением:
`1709 = 0`, `1713 = 0`, `1705` — направление `0` без поворота, `1706 = 0`.
Пустые строки игнорируются. Строка с пустым типом, нарушенной структурой,
некорректным числом или значением вне диапазона пропускается с
предупреждением.

## Преобразование типов

| CityGuide `TYPE` | Neoline |
| --- | --- |
| `18059`, `18951`, `18925` | `0x06` |
| `18952` | `0x01`, `flags = 0x02` |
| `18958`, `18950` | `0x4A` |
| любой другой непустой | `0x06` с предупреждением |

Направленность из тега `1713` преобразуется так:

| CityGuide | Neoline |
| --- | --- |
| `0` | `1`, одно направление |
| `1` | `1`, одно направление |
| `2` | `0`, все направления |

`0` и `1` описывают один контролируемый поток; встречное направление в
bkm — отдельная строка. По выгрузке 2026-09-19 записи с `0` и `1`
статистически неразличимы: встречная запись в радиусе ~50 м есть у 80 % и
78 %, совпадают распределения типов, скоростей и дистанций, вендор кодирует
обе как `direction_type = 1`, `tol = 0`. Вероятно, это режим съёмки
(«в лоб»/«в спину»), для Neoline не значимый. Прежнее прочтение `1` как
«оба направления» давало лишние оповещения на встречке.

Круговые камеры записываются по семантике RevM60: `direction_type = 0`, без
флага `0x20` и без принудительного допуска 5°.
