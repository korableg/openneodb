# CityGuide Speedcam v2

Каталог содержит `CityGuideReader`, который только читает CityGuide BKM и
возвращает нормализованные `CameraRecord`.

## Формат

Файл — текст в кодировке CP1251 с CRLF или LF. Заголовок имеет фиксированный вид:

```text
2|Radars|1251
```

Каждая следующая строка:

```text
TYPE|ID|LAT|LON|TAG|VALUE|TAG|VALUE|...|
```

| Поле или тег | Значение |
| --- | --- |
| `TYPE` | тип объекта CityGuide |
| `ID` | идентификатор; при конвертации не используется |
| `LAT`, `LON` | широта `0`…`90` и долгота `0`…`180` в градусах |
| `1709` | ограничение скорости, `0`…`255` км/ч |
| `1713` | тип луча, `0`…`2`; `1` — сектор, `2` — прямая |
| `1705` | первый азимут камеры, `0`…`359` градусов |
| `1706` | дистанция первого направления, целое число метров ≥ `0` |
| `1707` | второй азимут камеры, `0`…`359` градусов |
| `1708` | дистанция второго направления, целое число метров ≥ `0` |

Значения тегов `1713`, `1705`…`1708` описаны в
[руководстве CityGuide, стр. 106](https://gpsmobile.com.ua/files/Manual/CityGuide7.pdf#page=106).

Координаты сохраняются как `floor(value × 10000)`.

## Преобразование типов

| CityGuide `TYPE` | Neoline |
| --- | --- |
| `18059`, `18951`, `18925` | `0x06` |
| `18952` | `0x01`, `flags = 0x02` |
| `18958`, `18950` | `0x4A` |
| любой другой непустой | `0x06` с предупреждением |

## Направления и дистанции

Тег `1713` проверяется на диапазон `0`…`2` и не задаёт `direction_type`.
Направленность определяется наличием азимутов:

| Азимуты CityGuide | Записи Neoline |
| --- | --- |
| задан только `1705` | одна запись: `direction_type = 1`, азимут из `1705`, дистанция из `1706` |
| задан только `1707` | одна запись: `direction_type = 1`, азимут из `1707`, дистанция из `1708` |
| заданы `1705` и `1707` | две записи с `direction_type = 1`, каждая со своим азимутом и дистанцией |
| оба азимута отсутствуют или пусты | одна запись: `direction_type = 0`, `direction = 0`, дистанция из `1706` |

Каждый заданный азимут переводится в направление движения как
`(азимут + 180) % 360`. Числовое значение `0` задаёт азимут: результат —
`direction = 180`, `direction_type = 1`. Пустая строка и строка из пробелов
считаются отсутствующим азимутом. Две записи сохраняют одинаковые
координаты, тип камеры, флаги и скорость; угол между направлениями не
ограничен. Значение `direction_type = 2` не используется.

Дистанция делится на 10 с округлением вниз. Значения от 1 до 9 м
преобразуются в 100 м; значения больше 2000 м ограничиваются 2000 м.
Оба случая сопровождаются предупреждением с номером тега. Значение `0`
сохраняется как `0` и обозначает дистанцию 500 м в RevM60. Дистанции
направлений без заданного азимута не используются, кроме `1706` для
ненаправленной записи.

## Пропуски и ошибки

Отсутствующие, пустые или пробельные `1709` и `1713` получают значение `0`
с предупреждением. Используемые дистанции `1706` и `1708` получают значение
`0` с предупреждением при отсутствии или пустом значении. При отсутствии
обоих азимутов выдаётся предупреждение о выборе всех направлений.

Пустые строки игнорируются. При повторении тега используется последнее
значение с предупреждением. Неизвестные теги игнорируются. Строка с пустым
типом, нарушенной структурой, некорректным числом или значением вне диапазона
пропускается целиком с предупреждением. Ошибка второго направления также
исключает первую запись этой строки. `stats.read` считает непустые входные
строки, `stats.skipped` — пропущенные строки.

Неверный заголовок, пустой файл или ошибка декодирования CP1251 вызывают
`CityGuideFormatError`.
