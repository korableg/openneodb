# neoline

Генерация файлов баз камер для регистратора Neoline X-COP 9000c.

## Формат данных
Получен путём сравнения баз радаров 9000c и R750.

### Заголовок
Содержит магическую константу и размер базы без заголовка. Полный размер
файла равен `0x440 + N × 24`, а длина полезной нагрузки в `0x107` —
`0x40 + N × 24`.

| Смещение | Размер | Содержимое                                                                    |
| -------- | ------ | ----------------------------------------------------------------------------- |
| `0x000`  | 5      | ASCII `BRMSC`                                                                 |
| `0x005`  | 2      | Нули                                                                          |
| `0x007`  | 5      | ASCII `JHKIM`                                                                 |
| `0x00C`  | 244    | Нули                                                                          |
| `0x100`  | 7      | Одинаковые байты в обоих файлах `24 00 02 00 00 00 00`, назначение неизвестно |
| `0x107`  | 4      | `0x40 + N × 24` (размер файла минус `0x400`), `uint32 little-endian`        |
| `0x10B`  | 245    | Нули                                                                          |
| `0x200`  | 512    | Внутреннее имя файла: ASCIIZ, остаток поля заполнен нулями. У 9000c всё поле нулевое, у R750 — `X-COP_NLE45_Baza_GPS.db` |

### Данные
| Смещение | Размер   | Содержимое                                                                                                             |
| -------- | -------- | ---------------------------------------------------------------------------------------------------------------------- |
| `0x400`  | 16       | Заполнение `FF`                                                                                                        |
| `0x410`  | 8        | Шесть ASCII-цифр даты в формате `DDMMYY` и два нулевых байта                                                           |
| `0x418`  | 8        | Заполнение `FF`                                                                                                        |
| `0x420`  | 4        | `32 44 F8 39` (9000c), `32 44 F8 3A` (R750); байты неизвестного назначения                                             |
| `0x424`  | 3        | `00 01 01`; байты неизвестного назначения                                                                              |
| `0x427`  | 9        | Заполнено `FF`                                                                                                         |
| `0x430`  | 4        | Количество записей N, `uint32 little-endian`; должно совпадать с `(размер файла − 0x440) / 24`, иначе база отвергается |
| `0x434`  | 12       | Заполнено `FF`                                                                                                         |
| `0x440`  | `24 × N` | Массив из N записей по 24 байта                                                                                         |

При обновлении с карты прошивка отбрасывает файлы больше `0x300000` байт,
поэтому база может содержать не более 131 026 записей.

Записи в массиве **отсортированы по убыванию широты**. Для одинаковой
широты следует использовать стабильную сортировку, сохраняя исходный
порядок. Два направления одной камеры обычно кодируются парой записей с
одинаковыми координатами и азимутами, отличающимися примерно на 180°.

### Структура записи
Размер записи — 24 байта, многобайтовые числа имеют порядок `big-endian`.
Открытая запись обфусцируется XOR-ключом
`A3 AE CB 2C 7D 99 80 46 4A 00 13 AD 8A 3A 56 3C 0C 5A 08 73 3B 6F EF 78`:
каждый байт ключа применяется к соответствующему байту записи. Запись с
индексом `i`, где `0 ≤ i < N`, расположена по адресу `0x440 + 24 × i`.

| Смещение | Размер  | Содержимое                                                                                                                                                                               |
| -------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `+0`     | 1 байт  | Тип объекта: `uint8`, см. таблицу ниже                                                                                                                                          |
| `+1`     | 4 байта | Широта: `uint32 / 10000`, градусы северной широты. Хранится `floor(широта × 10000)`                                                                          |
| `+5`     | 4 байта | Долгота: `uint32 / 10000`, градусы восточной долготы. Хранится `floor(долгота × 10000)`                                                                      |
| `+9`     | 2 байта | Направление движения машин: `uint16`, 0–359 градусов                                                                                                               |
| `+11`    | 1 байт  | Направленность: `uint8`; `0` - во все стороны, `1` - в одну сторону, `2` - в обе стороны                                                                                        |
| `+12`    | 1 байт  | Ограничение скорости: `uint8`, км/ч; `0` — не задано (посты, безрадарные комплексы)                                                                                             |
| `+13`    | 4 байта | Широта второй точки: `uint32`, хранится `floor(широта × 10000)`; `0` — второй точки нет                                                         |
| `+17`    | 4 байта | Долгота второй точки: `uint32`, хранится `floor(долгота × 10000)`; `0` — второй точки нет                                                        |
| `+21`    | 1 байт  | Битовая маска: `uint8`; `0x02` — безрадарный комплекс; `0x20` — у камер «во все стороны» (направленность `0`), всегда идёт вместе с допуском по курсу 5° в следующем поле `+22`                                                                                                                           |
| `+22`    | 1 байт  | Допуск по курсу: `uint8`, градусы: значения `1`…`45` используются как есть, `0` или `>45` заменяются прошивкой на 20°                                                              |
| `+23`    | 1 байт  | Дистанция предупреждения: `uint8 × 10`, метров. `0` — по умолчанию, 500 м; значения меньше 100 м поднимаются до 100, больше 2000 м — сброс в 500                              |

Круговые камеры кодируются по-разному. Для RevM60 следует использовать
`dirtype = 0`. Вендорский шаблон, возможно рассчитанный на новые прошивки,
использует `dirtype = 1`, `flags |= 0x20`, `tol = 5`. RevM60 передаёт
дальше только `flags & 0x1F`, отбрасывая биты `0x20`, `0x40` и `0x80`.
Бит `0x02` лишь коррелирует с безрадарными комплексами во внешних базах;
его точная семантика не подтверждена.

### Типы объектов
Значение типа указано после XOR-декодирования. Устройство различает лишь
несколько категорий, каждая привязана к своему пункту меню:

| Тип            | В файле          | Содержимое                                                                                                                |
| -------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `0x01`         | `A2`             | Стрелка                                                                                                                   |
| `0x04`         | `A7`             | Участок контроля средней скорости с заполненной второй точкой; в свежих базах отсутствует                                 |
| `0x06`         | `A5`             | Стационарный радар, самый массовый тип                                                                                    |
| `0x07`         | `A4`             | Пост ДПС                                                                                                                  |
| `0x0B`         | `A8`             | Муляж камеры                                                                                                              |
| `0x0C`         | `AF`             | Стрелка без радарного модуля, только видеофиксация                                                                        |
| `0x2B`, `0x2C` | `88`, `8F`       | Стационарный радар, подтипы                                                                                               |
| `0x4A`         | `E9`             | Контроль средней скорости без второй точки; управляется внутренней настройкой, не выведенной в XML, значение по умолчанию не установлено |
| `0x4C`         | `EF`             | Спец-тип: лимит принудительно 0, дистанция 200 м, оповещение только при скорости не менее 20 км/ч; в базах не встречается  |
| `0x29`…`0x50`, прочие | `тип XOR 0xA3` | Обобщённая камера; отдельные подтипы прошивкой не различаются                                                              |
| `0x00`, `0x02`, `0x03`, `0x05`, `0x08`…`0x0A` | `A3`, `A1`, `A0`, `A6`, `AB`, `AA`, `A9` | Неактивные типы: оповещение не выдаётся |
